# Burp Proxy History Colorer

Расширение Burp Suite синхронизирует прокомментированные запросы из Organizer и
восстанавливает их Notes и цвет для повторных запросов в Proxy history.

## Требования

- Burp Suite Professional с Montoya API 2026.7 или новее
- Java 21

## Как работает сопоставление

Эндпоинт определяется по:

```text
HTTP method + scheme + host + effective port + path
```

Query string и body не учитываются. Поэтому `GET /users?page=1` и
`GET /users?page=2` считаются одним эндпоинтом, а `GET /users` и `POST /users` —
разными.

Расширение каждые две секунды читает все записи Organizer независимо от того,
были они отправлены из Proxy, Repeater, Scanner или другого инструмента:

- элементы без Notes игнорируются;
- Notes и установленный highlight color переносятся в новые совпавшие запросы;
- если цвет не задан, используется серый;
- если один эндпоинт встречается несколько раз, побеждает элемент с максимальным
  Organizer ID, то есть самый новый, а все старые дубли окрашиваются в розовый.

Актуальный реестр кэшируется внутри Burp project через Montoya Persistence API.
Organizer остается источником истины: удаленный из него элемент исчезнет из
реестра при следующей синхронизации. Уже существующие строки Proxy history
ретроактивно не изменяются — аннотации применяются, когда совпавший запрос снова
проходит через Proxy.

## Сборка

```bash
./gradlew clean test build
```

JAR будет создан в `build/libs/proxy-history-colorer-0.2.0.jar`.

## Установка

1. Откройте `Extensions` → `Installed`.
2. Нажмите `Add`.
3. Выберите тип `Java` и собранный JAR.
4. Убедитесь, что в Output появилось сообщение `Proxy History Colorer loaded`.

## Ручная проверка

1. Перехватите запрос, например `GET https://example.com/api/users?page=1`.
2. В Proxy history добавьте ему Notes и отправьте запрос в Organizer.
3. При необходимости назначьте строке Organizer цвет.
4. Подождите до двух секунд.
5. Повторите запрос с другим query, например `/api/users?page=2`.
6. Новая строка Proxy history должна получить прежние Notes и выбранный цвет
   (или серый, если цвет не был задан).
